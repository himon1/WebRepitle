# Web-spider
light-weight spider served for edge web grab 
## 📖 项目简介
一个轻量化的爬虫程序  
支持爬虫进行微博、贴吧、知乎等主流平台的公开信息抓取并批量导出爬取内容，保存为本地文件。

### 🔧 技术原理
基于**Selenium+beautifulsoap**编写  
调用msedgedriver等浏览器自动化驱动程序  
利用cookie_editor等插件获取cookie 字符串信息并以json形式使用  
无需逆向复杂的加密算法，大幅降低技术门槛  

## ✨ 功能
-   自动登录知乎（支持扫码登录，保存并加载 Cookies）  
  -   批量抓取指定用户的回答链接 - 将回答正文转换为 Markdown 格式
    -  自动下载回答中的图片并替换为本地路径  
   -  为所有导出的回答生成目录索引 `README.md`  

## 📦 依赖 请确保已安装以下依赖：   
requests   
beautifulsoup4   
html2text   
selenium  

🚀 使用方法  
1.下载并安装 Microsoft Edge WebDriver，并修改脚本中的 EDGE_DRIVER_PATH。  

2.修改 USER_ANSWERS_URL 为你要抓取的页面。  

3.首次运行时需要获取cookie字符串，登录后 Cookies 会保存到本地，后续运行可自动登录。

4.运行脚本    

5.导出的回答会保存为 Markdown 文件，图片保存到 images/ 文件夹，并生成一个索引 README.md。
